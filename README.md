## 5. Inventário de Frameworks e Ferramental Proprietário

### 5.1 Aegis / AegisCodexEngine — Client Hardening & DOM Mutation Firewall
- **Repositório:** [github.com/jo0natan/Aegis](https://github.com/jo0natan/Aegis)
- **dom_guard_v2.js / Aegis_console_v8.js:** Blindagem de Clipboard Layer 12 (interceptação estrita de `readText`, `writeText`, `execCommand` e eventos `copy`/`cut`/`paste`); sistema `MutationPolicySystem` indexado via `WeakMap`; congelamento em profundidade de protótipos de nós DOM (`Node`, `Element`, `HTMLElement`, `Document`, `console`); purga de nós desconectados em memória (`purgeDetachedNodes`); Shadow Hooks sobre `WebAssembly.instantiate`, probes bidirecionais de `WebSocket`, `Worker.postMessage` e `IDBObjectStore.put`.
- **WAKE_LOCK_COMPLETO.js / antbot7.js:** Preservação contínua de execução via Screen Wake Lock e travas não-resolvidas de Web Locks (`keep-alive-lock`); osciladores WebAudio em ganho nulo anti-throttling; congelamento de estado sintético (`visibilityState='visible'`, `hasFocus()=true`); inibição de eventos de perda de foco no `EventTarget`; emulação biomecânica com interpolação `lerp` e ruído gaussiano.

### 5.2 tcp_udp_orchestrator — Proxy de Inspeção & Interceptação TLS
- **Repositório:** [github.com/jo0natan/tcp_udp_orchestrator](https://github.com/jo0natan/tcp_udp_orchestrator)
- Implementação integral em Node.js CommonJS (zero-framework; `node-forge` e módulos nativos de rede, TLS, streams e crypto).
- Suporte a túneis SOCKS5 RFC 1928 (IPv4, nomes de domínio, IPv6).
- Módulo MITM com autoridade certificadora efêmera e roteamento transparente via Packet Filter (`pf` `rdr` / `natlook`) em ambientes BSD/macOS.
- Parser de streams HTTP/1 (`http1-stream-inspector.js`) com tolerância a dados truncados e descompressão de payloads encadeados.
- Geração sintética de arquivos PCAP compatíveis com Wireshark e console visual em tempo real via Server-Sent Events (SSE).

### 5.3 Recon Orchestrator Suite (Castville Security)
- Suíte em Perl 5.34 para auditoria externa de alta cadência (`recon_jntg.pl`, `recon-v4.pl`, `recon-v3.pl`).

- Coleta passiva em endpoints: extração de chaves e segredos em artefatos JavaScript (AWS, Stripe, JWTs, rotas internas).
